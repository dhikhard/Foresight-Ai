Model Formulation & Optimization Details

1. Closed-Form Ridge Objective:

min ||y - Xw - b||² + α * ||w||²

Solved via normal equations on internally centered data: w = (X_c^T X_c + αI)⁻¹ X_c^T y_c. Validation MAE selected optimal α = 0.01.

2. NumPy Coordinate Descent Elastic Net:

min (1/2n)*||y - Xw - b||² + α*ρ*||w||₁ + α*(1-ρ)/2*||w||²

Cyclic coordinate descent with soft-thresholding. With objective scaling 1/(2n), α=0.01 imposed an L1 penalty exceeding return cross-correlations, shrinking all weights to 0.

Why is the Test R² negative for all models?

In standard machine learning, an R² of 0 represents predicting the mean of the test set. Because ForeSightAI enforces zero look-ahead bias, the baseline model predicts the training set mean (2000–2018), not the unknown future test mean. In the 2023–2026 test period, the target variance was slightly smaller than historical levels, meaning predicting the training mean incurs a slightly negative R² (-0.0041). Ridge regression (Test R² = -0.0095) attempted to fit subtle lag dynamics that failed to generalize out-of-sample, confirming the Martingale hypothesis.
